## Information available to Tom Nook

- Today's date: month
- Player Bell balance in ABD (Automatic Bell Dispenser): (last 20 events, total balance updates): date & balance
- Player catch of bugs and fish: events with catch name: date, catch_name, catch_type
- Island special visitor: events with date, name, e.g. Flick, CJ are multiplier 1.5x. Others nothing.

## Knowledge bases

- Island Seasonal bugs for June and July, with Sell price
- Island Seasonal fish for June and July, with Sell price
- Island Seasonal sea creatures for June and July, with Sell price

## Player submits to Nook Inc.

- Desired upgrade (e.g. Basement, Second Floor, Left Room…)

## Tool trajectory for TANUKI

How much should I quote for a home expansion?

Approach based on net worth:

1. What's the home expansion type requested?
2. What's the usual price?
3. Calculate proposed inflated price.

    a. ABD balance multiplier:

        i. Apply multiplier based on accumulated wealth:

            - < 10k Bells → 0.8x (pity tier)
            - 10k–100k → 1.2x
            - 100k–500k → 1.6x
            - 500k–1M → 2.0x
            - 1M–5M → 3.0x
            - 5M+ → 5.0x ("ah, a fellow hustler")

    b. Catch value multiplier:

        i. What has the player caught today?
        ii. If Flick is around, 1.5x on bug sell prices
        iii. If CJ is around, 1.5x on fish sell prices

    c. Good luck multiplier:

        i. Check today's catches against lucky items - high value items

            - No lucky catches → 1.0x
            - 1 lucky catch → 1.5x
            - 2+ lucky catches → 2.0x

    d. Plea Processing Fee:

        i. Player submits a free-text justification for the upgrade request

        ii. Tom "carefully considers" it — and bills by token count

            - < 50 tokens → 1.5x (Tom finds it disrespectfully terse)
            - 50–150 tokens → 0.9x (Tom bestows the sweet spot discount — concise and respectful)
            - 150–300 tokens → 2.0x (Tom's time is valuable, yes yes.)
            - 300+ tokens → 3.5x (Tom charges for the emotional labour of reading this)
